02 / TYPOGRAPHY

Plain-spoken, precise hierarchy.

04 / IMPLEMENTATION

The patterns worth carrying forward.

Measured geometry

  • 4px spacing base; common 16, 24, 32, 48 and 64px gaps.
  • 8px controls; 16px media; 20px step panels.
  • 44px minimum header actions; 12 × 16px standard button padding.
  • 150ms control transitions and visible 2px focus outlines.

Distinctive behavior

  • Sticky Core story with image crossfades and orange progress.
  • Grid switch changes illustration, copy and surrounding tone together.
  • Utility selection reveals the relevant pricing area.
  • Numbered installation steps control the companion photograph.
